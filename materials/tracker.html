What the dominant tag means:

Dominant Diagnosis Fix
SELECTION You're opening the wrong questions Re-read 03-playbook.md. Do a set-selection drill.
SLOW Execution speed Arithmetic drills. Stop writing full working.
CARELESS Process discipline Slow down on the last read of the question stem. Each careless error is a 4-mark swing.
BLIND (DILR) Set-type exposure More sets, fast, abandoning early. Breadth over depth for now.
KNOWLEDGE Actual gap Should be near zero in QA. If not, name the topic and fix it directly.
